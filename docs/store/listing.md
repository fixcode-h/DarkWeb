### 详细说明

```
Drak 给所有网站加上舒服的暗色模式。

它不是把整个页面简单反色，而是先判断每个颜色在页面里的角色（背景、文字、边框、阴影、强调色），再在 OKLCH 色彩空间里分别重新配色。所以边框和层次还在，品牌色认得出来，图片和视频保持原样。

主要功能
• 自动适配：打开即用，绝大多数网站不需要任何设置
• 每个网站单独选择模式：自动、动态配色、网站自带的暗色、滤镜反色、关闭
• 多种配色主题，背景亮度、文字对比度、饱和度都可调
• 可以定时启用，比如只在晚上开启
• 白底的截图和图表自动降低亮度，图片亮度可调
• 可以设置为只在系统处于深色模式时启用
• 快捷键 Alt+Shift+D 一键开关当前网站
• 网页翻译：双语对照或仅显示译文，默认 Google 翻译，也可选微软、DeepL 或 AI 大模型
• 页面加载时不闪白
• 高级用户可以为单个网站编写修正规则

隐私
Drak 不收集任何数据，没有服务器，没有统计和广告代码。暗色配色全部在你的浏览器里完成；只有你主动翻译页面时，页面文字才会发给你选择的翻译服务。

开源
源代码：https://github.com/fixcode-h/DarkWeb
问题反馈：https://github.com/fixcode-h/DarkWeb/issues
```

## Privacy（隐私权规范）

**单一用途说明**

```
让用户更舒适地阅读网页：在本地把页面重新配色为暗色主题，并可按需把页面翻译成用户的语言；两者都可以按网站调整或关闭。
```

> 加入网页翻译后，单一用途统一表述为“网页阅读增强”。如果审核仍认为是两个用途，备选做法是把名称改成“Drak 暗色模式与翻译”之类，或把翻译拆成独立扩展。

**权限理由**

| 权限 | 理由 |
| --- | --- |
| 主机权限 `<all_urls>` | 暗色模式要在用户访问的所有网站上生效，所以需要在每个页面注入配色脚本和样式。另外，跨域的样式表和图片在页面内读不到内容，需要由扩展的后台向原地址再请求一次，才能分析并改写其中的颜色。所有处理都在本地完成，不上传任何内容。 |
| `storage` | 保存用户设置（全局开关、各网站的模式、亮度、对比度、自定义站点规则）。 |
| `unlimitedStorage` | 在本地缓存每个网站算好的暗色样式，下次打开时直接套用，避免闪白。网站多了以后缓存会超过默认的 10 MB 配额。 |
| `scripting` | 用 `chrome.scripting.registerContentScripts` 按用户设置动态注册内容脚本（用户关闭的网站会被排除）；用户在当前页面重新开启时，用 `executeScript` / `insertCSS` 立刻生效而不用刷新。 |
| `alarms` | “定时启用”功能：按用户设定的时间段（或日落到日出）自动开关暗色模式，需要定时唤醒后台来切换。 |
| `contextMenus` | 在页面右键菜单里加入“翻译此页面 / 显示原文”“翻译选中的文字”“阅读模式”“屏蔽页面元素”。 |

主机权限的理由里还要补一句：网页翻译时，后台需要向用户选择的翻译服务（Google、微软、DeepL 或用户自填的 AI 接口）发请求，并在用户开启“总是翻译此网站”的页面注入翻译脚本。

**是否使用远程代码**：否。所有脚本都打包在扩展里。

**数据使用**：勾选“网站内容”（用户主动翻译时，页面文字会发给用户选择的翻译服务），其他类别不勾选。底部三项声明全部勾选：不出售数据、不用于无关用途、不用于信用评估。

**隐私权政策网址**：`https://github.com/fixcode-h/DarkWeb/blob/main/PRIVACY.md`（需要仓库是公开的；如果仓库是私有的，把 `PRIVACY.md` 的内容放到任意一个公开网页上）

## Distribution（分发）

- 付费方式：免费
- 公开范围：公开。想先小范围试用可以选“不公开”（只有拿到链接的人能安装）
- 地区：所有地区

## 以后加功能时要同步改的地方

商店审核时会对照包里的实际行为检查这里的声明，功能变了而声明没变是最常见的被拒原因。

- **阅读增强**（0.3.0）：划词翻译、字体与排版、护眼滤镜。没有新增权限；划词翻译只在用户选中并点开时把选中的文字发给已选的翻译服务，与整页翻译的数据披露相同。字体和滤镜全在本地。
- **阅读模式、元素屏蔽、自定义 CSS**（0.4.0）：全部在本地处理，不发送数据，没有新增权限；Readability 打包在扩展里，不加载远程代码。
- **网页翻译**（已上线）：数据披露、隐私政策、权限理由已按翻译功能更新。新增翻译引擎时，把它的接口域名补进 `PRIVACY.md`。
- **单一用途**：商店要求一个扩展只有一个明确的用途。暗色模式加网页翻译算两个功能，直接放在一起有被拒的风险。稳妥的做法是把名称、简介和单一用途说明统一成一个更大的用途（例如“网页阅读增强：暗色模式与翻译”），或者把翻译做成另一个扩展。
- **新增权限**：每加一个权限都要在这里补一条理由。新增权限的版本，已安装的用户会被要求重新确认，扩展在确认前会被停用。
- **远程规则**：设置里预留了远程规则开关。如果以后从网络下载站点规则，只能下载数据（选择器、颜色配置），不能下载并执行脚本，否则违反“禁止远程代码”的规定。
