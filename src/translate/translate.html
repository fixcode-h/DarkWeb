网页翻译

在弹窗里点“翻译此页面”，或按 AltShiftT，或在页面上右键选择“翻译此页面 / 显示原文”。改动自动保存。

DeepL

需要自己的 DeepL API 密钥（免费版密钥以 :fx 结尾，会自动使用免费版接口）。

AI 大模型

任何兼容 OpenAI chat/completions 的接口都可以用。译文通常最自然，但更慢，并按接口方的价格计费。

侧边翻译按钮

不显示按钮的网站，每行一个域名或 IP:端口。也可以在按钮旁的“本站隐藏”或弹窗里设置。

总是翻译的网站

每行一个域名或 IP:端口（例如 news.ycombinator.com、192.168.1.10:8080），也可以直接粘贴完整网址。打开这些网站的任何页面时自动翻译。
