站点修正规则

JSON 数组，每条规则可用的字段：match（必填，如 "*.example.com"）、mode（dynamic / native / filter / off）、 native、ignore、invert、keepImage、vars、css。用户规则优先于内置规则。

缓存

      
为了重复访问时不闪白，Drak 会按网站缓存上次生成的配色样式。超过 30 天未访问的会自动清理。
