# DarkWeb (Drak)

通用自适应暗色模式浏览器插件（Chrome / Edge，Manifest V3）。按颜色在页面中的角色（背景、文字、边框、阴影、强调色）在 OKLCH 色彩空间里重新配色，保留边框和层次，不做整页反色。

## 分支

- `dev`：日常开发，推送后跑 CI（类型检查、单元测试、端到端验收）
- `main`：发布分支，合并后 GitHub Actions 自动构建、验收并发布扩展包（Releases 里的 `drak-<版本>.zip`，发布说明会列出这个包相对上一个包的调整），配置密钥后还会同步到 Chrome 应用商店，见 [docs/store/README.md](docs/store/README.md)

## 本地开发

```bash
npm install
npm run build        # 输出到 dist/，在 chrome://extensions 里“加载已解压的扩展程序”选 dist
npm test             # 颜色引擎单元测试
npm run test:e2e     # 构建后在本地仿真的知乎 / B 站页面上跑端到端验收
```

首次运行端到端测试前需要 `npx playwright install chromium`。

## 使用

- 弹窗：全局开关、本站模式（自动 / 动态 / 原生 / 滤镜 / 关闭）、配色主题、亮度 / 对比度 / 饱和度 / 图片亮度、白底图降亮度、跟随系统、定时启用
- 配色主题：默认（极淡的冷灰底 + 米白文字）、纯黑（OLED）、柔和、暖色护眼、午夜蓝；只给中性色染色，品牌色和强调色保持原样。主次文字分档（正文、次要、占位文字逐级变暗），彩色按钮和标签保留品牌色但压低亮度，浅色提示条保留一点色调
- 定时启用：设置起止时间（可跨午夜），时段外不注入任何脚本
- 快捷键 `Alt+Shift+D`：开关当前网站；`Alt+Shift+A`：全局开关
- “本站关闭”按站点记录：域名（含子域名），或 IP / localhost 加端口（如 `192.168.1.10:8080`），与具体页面地址无关；不同端口算不同站点
- 网站自己已经开了暗色主题时自动让位，不再叠加一层；网站中途切换主题也会跟着切换。判断看页面实际画出来的颜色：可见文字的真实颜色、跳过 Cookie 提示之类的小浮层、分区各自深色的长页面也认得出
- 确认过是暗色的网站会记住，下次打开从一开始就不上色（不再先改一遍再撤掉），加载完成后仍会复查，网站换回浅色会重新接管
- 选项“网站自带暗色时自动跳过”可以关掉；单个网站识别错了，在弹窗里点“本站仍然启用暗色”（等同于本站选“动态”）
- 右键菜单“暗色模式：开关本站”
- 设置页：外观与启用条件、按站点的模式、站点修正规则（JSON，用户规则优先于内置规则）、设置导入导出、缓存管理

## 网页翻译

- 页面右边缘的“译”按钮、弹窗里的“翻译此页面”、快捷键 `Alt+Shift+T`、右键“翻译此页面 / 显示原文”都可以开始翻译，再触发一次还原
- 侧边按钮贴在屏幕右边缘，平时只露出一半，鼠标移上去滑出；按住可上下拖动（始终吸附在右边缘）；悬停可“本站隐藏”或“全部隐藏”，在弹窗或翻译设置页恢复
- 引擎：Google 翻译（默认）、微软翻译，两者免密钥、互为备用；DeepL 和 AI 大模型（OpenAI 兼容接口）需要在“翻译设置”里填自己的密钥
- 显示方式：双语对照（原文下方显示译文，默认）或仅显示译文；链接、加粗等行内格式保留，代码不翻译
- 只翻译视口附近的内容，滚动和页面新增内容自动跟进；已是目标语言的段落跳过
- “总是翻译此网站”按域名或 IP:端口识别，对该站点所有页面生效

## 阅读增强

弹窗底部“阅读增强”打开设置页（`src/enhance/`），改动自动保存，已打开的页面立即生效：

- 划词翻译：选中文字后出现“译”图标，点开是译文卡片（可复制）；也可以设成松开鼠标立即翻译，或右键“翻译选中的文字”。引擎和目标语言跟随翻译设置，选中的已是目标语言时译成英文；输入框里选字不弹出
- 字体与排版：网页字体换成黑体 / 宋体 / 楷体或自定义字体，段落行高 1.6 / 1.8 / 2.0，文字稍微加粗；代码、公式、图标字体不受影响
- 护眼滤镜：暖色（减少蓝光）、调暗、灰度，强度 5%–80%；覆盖层不挡点击，打印时不带
- 可以按网站排除（含子域名）
- 阅读模式：页面上右键“阅读模式”，用 Mozilla Readability 抽出正文重新排版，可调字号、栏宽、黑体 / 宋体、跟随系统 / 深色 / 浅色 / 米黄，偏好会记住；Esc 退出。正文经过白名单清洗（去掉脚本、事件属性、`javascript:` 链接）
- 屏蔽页面元素：右键“屏蔽页面元素…”进入点选，可“扩大 / 缩小”调整范围，Enter 确认；按网站保存为选择器，下次打开自动隐藏，可“全部恢复”
- 按网站自定义 CSS：在设置页按网站编辑隐藏规则和自定义 CSS
- 输入框翻译：在输入框、评论框、可编辑区域里写完后快速连按三次空格，内容替换成设置里的语言（默认英文），Ctrl+Z 撤销；密码框不处理
- YouTube 双语字幕：播放器右下角“译”按钮或设置页开关，原字幕下方显示译文（翻译设置里的目标语言），自动生成的字幕也能用；默认关闭
- 阅读模式和屏蔽元素默认没有快捷键，可在 `chrome://extensions/shortcuts` 设置

## 版本号与更新

- 每次 `main` 出包，版本号自动递增：`<package.json 的 version>.<构建序号>`，例如 `0.1.0.7`。包名、Release 标题、扩展管理页里显示的版本都是这个号。要升 `0.2.0` 这样的大版本时改 `package.json` 的 `version`。
- 每个 Release 的说明和包里的 `CHANGES.md` 会列出相对上一个包合并了哪些改动（取自 PR 标题，所以 PR 标题要写清楚改了什么）。
- 扩展 ID 是固定的（manifest 里的 `key`），本地安装新包会覆盖旧版并保留设置，不会多出一个扩展。更新方法：把新的 zip 解压到**同一个文件夹**覆盖旧文件，在 `chrome://extensions` 点扩展卡片上的刷新按钮；或者直接把新 zip 拖进 `chrome://extensions`。
- 以前装过没有固定 ID 的旧包的话，它不会被覆盖，需要手动移除一次。

## 性能

- 样式表改写按值缓存，同样的颜色值只解析一次；CSS 变量只为真正用到的角色（背景 / 文字 / 边框 / 阴影）生成影子变量，变量多的网站（GitHub 等）样式计算时间少约四成
- 再次访问时有上次留下的覆盖缓存兜底，几万条规则的大样式表放到首屏画出来之后再改写（YouTube 再次打开的首屏时间接近不装插件）
- 跨域图片的分析（需要后台再下载一份采样）推迟到页面加载完成后；JPEG 这类不可能需要反转的图片不再下载
- “页面过重”保护以前会把嵌套调用的耗时重复累加，普通页面也被误判，已修正
